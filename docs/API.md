# API Reference — islamic-astro-ts

## Exports
- `calculatePrayerTimes(options)`: Computes daily prayer times for given coordinates.
- `calculateQibla(latitude, longitude)`: Calculates forward azimuth bearing and distance.
- `getNextPrayer(options)`: Real-time upcoming prayer determination.
- `formatDateToTimeString(date, timeZone)`: Localized 24h formatter.
